# Code of Conduct

## Our Standard

Underscore is a project for people interested in programming, language design, compilers, systems programming, and computer science.

Contributors and community members are expected to treat each other with respect and to keep discussions constructive and focused on the project.

## Expected Behavior

Examples of positive behavior include:

* Being respectful and considerate of others.
* Giving constructive feedback.
* Discussing ideas rather than attacking people.
* Being open to different approaches and perspectives.
* Giving appropriate credit to other contributors.
* Taking responsibility for mistakes and correcting them.
* Keeping technical discussions focused and productive.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, intimidation, or personal attacks.
* Discriminatory or hateful conduct.
* Threats of violence or other harm.
* Deliberate disruption of discussions or development.
* Publishing someone's private information without permission.
* Impersonating contributors or maintainers.
* Deliberately misrepresenting another person's work.
* Spam or unrelated promotional activity.
* Other behavior that would reasonably make participation in the project hostile, unsafe.

## Technical Disagreements

Disagreement is a normal and valuable part of software development.

Technical disagreements should focus on the code, design, implementation, or ideas being discussed rather than the people involved.

Strong criticism of an implementation is acceptable when it is made constructively and in good faith.

## Scope

This Code of Conduct applies to project spaces, including:

* GitHub issues
* Pull requests
* Discussions
* Project documentation
* Community spaces directly associated with Underscore

Maintainers may also consider behavior outside project spaces when it directly affects the safety or participation of the Underscore community.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the circumstances, maintainers may:

1. Ask someone to stop inappropriate behavior.
2. Remove inappropriate content.
3. Close or lock discussions, issues, or pull requests.
4. Temporarily restrict participation.
5. Permanently restrict participation from project spaces.

Enforcement decisions will be based on the circumstances and severity of the behavior.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, report it privately to the project maintainers.

Please avoid posting sensitive information publicly when making a report.

Security vulnerabilities should be reported according to [`SECURITY.md`](SECURITY.md).

## Good-Faith Participation

Underscore is an evolving project, and mistakes will happen.

The goal of this Code of Conduct is not to prevent disagreement or experimentation. It exists to make sure people can participate in the project without being subjected to harassment, threats, discrimination, or deliberate disruption.

Everyone participating in Underscore is expected to contribute in good faith.

## Attribution

This Code of Conduct is intended to provide a clear and practical standard for participation in the Underscore project.
