# Security Policy

## Supported Versions

Underscore is currently in pre-alpha development.

Security fixes are generally applied to the latest development version. Older versions may not receive security updates.

| Version                    | Supported |
| -------------------------- | --------- |
| Latest development version | Yes       |
| Older versions             | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in Underscore, please **do not create a public GitHub issue** containing the vulnerability details.

Instead, report the issue privately to the Underscore maintainers.

When reporting a vulnerability, please include:

* A description of the vulnerability
* The affected version or commit
* Steps to reproduce the issue
* A minimal example or proof of concept, if possible
* The potential impact of the vulnerability
* Any suggested fixes or mitigations, if you have them

Please give the maintainers reasonable time to investigate and address the issue before publicly disclosing it.

## What Should Be Reported?

Security reports may include issues such as:

* Compiler crashes caused by malicious input
* Arbitrary code execution caused by the compiler
* Unsafe code generation
* Unexpected file or system access
* Vulnerabilities in bundled libraries
* Build or distribution vulnerabilities
* Security issues in official Underscore tooling

Issues that are purely bugs without a security impact can be reported through the normal GitHub issue tracker.

## Disclosure

Once a vulnerability has been investigated and, where appropriate, fixed, the maintainers may publish information about the vulnerability and its resolution.

Security researchers and contributors who responsibly report vulnerabilities may be credited for their discovery, unless they request to remain anonymous.

## Third-Party Code

Underscore may depend on third-party software, libraries, or development tools. Security issues originating in those dependencies may need to be reported to their respective maintainers as well.

## Getting in contact

Currently, all private bug reports will not be done through GitHub and instead through Underscores website. All contact information to myself or the team is held there along with other details for safety.
