# Welcome to the language branch

The language branch is the branch with the technical stuff. 
It holds the open source compiler, current version test files along with the backend behind config files and all types of libraries.
For legal, Issues, Vulnerabilities, or updates to documentation or comments within files, refer to the main branches associate files.

# Compiler

The underscore compiler is currently written in C and follows a typical workflow of lex -> parse -> semantic -> codegen.
The compiler is completely open source, and will eventually be bootstrapped into underscore once the amount of syntax is applicable.
All files are under the compiler section with their individual sourcr and headers.
Everyday we're working to make it more optimized and adding more syntax for a broader use.
